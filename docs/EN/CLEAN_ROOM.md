## External data and weather

- **No** external data is downloaded or used: no weather, no airport coordinates, no runway maps,
  no NOP calendars beyond the provided files.
- The prompt indicated that weather would be useless for the targeted RMSE; it was therefore never
  requested, and nothing has been added that would make the solution non-reproducible outside the
  provided folder.
- Licensing consequence: prize eligibility requires "no non-open external data"; the project uses
  only the challenge data, so this point is satisfied by construction.

## Weather and non-provided variables: documented decision rather than silent one

No home-grown approximation (runway‑stand distance, distance traveled) is introduced without a
source in the provided files. The only derived quantities are aggregations of the provided columns
(network flows per slot, averages per STAND, deviation from scheduled times).
